# 祝你生日快乐 · 水果蛋糕

纯代码绘制的生日动画：开场「祝你生日快乐」→ 蛋糕场景 → 奶油水果双层蛋糕 + 悬浮气球 + 生日歌。

蛋糕、气球、文字、光效全部实时 3D 投影绘制，音乐由程序合成，**不需要任何外部图片或音频文件**。

## 运行

```bat
pip install pygame
python 生日星空.py
```

Windows 直接双击 `启动生日.bat`（脚本会自动找同目录的 .py，不怕中文文件名）。

## 操作

| 操作 | 效果                  |
| --- |---------------------|
| 点一下标题 | 开始，字变成星屑旋涡，转到生日蛋糕场景 |
| 按住拖动 | 旋转 3D 视角            |
| 单击空白处 | 星屑爆开                |
| 点击火苗 | 吹灭（吹灭会冒烟）           |
